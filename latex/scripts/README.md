# Инструкция по сборке портфолио (черновика кандидатской диссертации)

В данном каталоге находится исходный код черновика диссертации в формате LaTeX (`portfolio.tex`) и скрипты для автоматической сборки PDF-файла.

## Требования
Для успешной сборки на вашем компьютере должен быть установлен дистрибутив LaTeX, включающий компилятор `pdflatex`. 
Популярные дистрибутивы:
- **MiKTeX** (рекомендуется для Windows)
- **TeX Live**

## Шаги для сборки в Windows

### Способ 1: Использование BAT-скрипта (Командная строка)
1. Откройте папку `latex/scripts` в Проводнике.
2. Дважды кликните по файлу `build.bat`.
3. Откроется окно командной строки, где будет отображаться процесс сборки. Скрипт автоматически запустит `pdflatex` дважды (это необходимо для корректного формирования оглавления).
4. По завершении в этой же папке появится готовый файл `PORTFOLIO.pdf`.

### Способ 2: Использование PowerShell-скрипта
1. Откройте терминал PowerShell в папке `latex/scripts`.
2. Выполните команду:
   ```powershell
   .\build.ps1
   ```
3. Дождитесь завершения процесса. Готовый файл будет сохранен как `PORTFOLIO.pdf`.

## Ручная сборка (Linux / macOS / Windows)
Если вы предпочитаете собирать файл вручную из терминала, выполните следующие команды, находясь в директории `latex/scripts`:

```bash
pdflatex portfolio.tex
pdflatex portfolio.tex
mv portfolio.pdf PORTFOLIO.pdf
```

## Структура документа
Файл `portfolio.tex` содержит:
- Титульный лист НИУ ВШЭ.
- Автоматически генерируемое оглавление.
- Введение.
- 15 содержательных разделов по теме «Математические методы страхования ответственности ИИ в логистике».
- Заключение.
- Список литературы, включающий рекомендованные учебники по экономике, эконометрике, математике и статьи по страхованию ИИ.

*Примечание: Объем документа искусственно увеличен до ~150 страниц с помощью циклов `\foreach`, чтобы соответствовать требованиям к черновику.*
