# Требования кандидатского минимума и рекомендуемая литература

## Механико-математический факультет МГУ (Математика)
Кандидатский минимум включает экзамены по истории и философии науки, иностранному языку и специальной дисциплине (например, 1.1.5 Математическая логика, алгебра, теория чисел и дискретная математика).

**Рекомендуемая литература (1.1.5):**
1. Верещагин Н. К., Шень А. Математическая логика и теория алгоритмов. Части 1-3. М.: МЦНМО, 2012.
2. Боревич З.И., Шафаревич И.Р. Теория чисел. М.: Наука, 1985.
3. Яблонский С. В. Введение в дискретную математику. М.: Высшая школа, 2001.
4. Винберг Э. Б. Курс алгебры. М.: МЦНМО, 2013.

## Факультет вычислительной математики и кибернетики (ВМК) МГУ (Информатика)
Кандидатский минимум включает экзамены по истории и философии науки, иностранному языку и специальной дисциплине (например, 1.2.3 Теоретическая информатика, кибернетика или 2.3.5 Математическое и программное обеспечение вычислительных систем).

**Рекомендуемая литература (на примере 2.3.5):**
1. Ахо А., Сети Р., Ульман Дж. Компиляторы: принципы, техника реализации и инструменты. М., 2001.
2. Кнут Д. Искусство программирования. Т. 1 - 3. М., СПб., Киев: ИД "Вильямс", 2000.
3. Кормен Т., Лейзерсон Ч., Ривест Р. Алгоритмы, построение и анализ. М.: МЦНМО, 2000.
4. Назаров С. В., Широков А. И. Современные операционные системы. М.: Изд-во Бином, 2011.

## Экономический факультет МГУ (Экономика)
Кандидатский минимум включает экзамены по истории и философии науки, иностранному языку и специальной дисциплине (например, 5.2.1 Экономическая теория). Дополнительно требуется подготовка реферата по теме диссертации. Экзамен включает основную и дополнительную программу (по статьям).

**Рекомендуемая литература (общая для подготовки):**
1. Пиндайк Р. С., Рубинфельд Д. Л. Микроэкономика. М.: Дело, 2000.
2. Бланшар О. Макроэкономика. М.: Издательство НИУ ВШЭ, 2010.
3. Шведов А.С. Теория вероятностей и математическая статистика. М.: ВШЭ, 2005.
4. Вербик М. Путеводитель по современной эконометрике. М.: Научная книга, 2008.
5. История экономических учений (ИЭУ). Под ред. В.С. Автономова, О.И. Ананьина.

## Математические методы страхования ответственности ИИ в логистике
Для подготовки черновика кандидатской диссертации по данной теме рекомендуется следующая литература и нормативные документы:

**Рекомендуемая литература:**
1. Сабитов К. Т., Исаев Д. В. Возможности искусственного интеллекта в страховании // Столыпинский вестник. 2024. № 9. С. 142–146.
2. Маглинова Т. Г., Шупило О. М. Внедрение искусственного интеллекта в страховую отрасль // Цифровая экономика. 2023. № 5. С. 45–52.
3. Зезина Е. С., Кошелев Д. А. К вопросу о страховании рисков, связанных с использованием технологий искусственного интеллекта // Вестник Международного института рынка. 2025. № 2. С. 87-91.
4. Методические рекомендации Банка России по обеспечению информационной безопасности при разработке и применении искусственного интеллекта на финансовом рынке (утв. Банком России, 2025 г.).
5. InsurTech-платформы в логистике: трансформация страхования грузоперевозок на основе телематики и искусственного интеллекта (Евразийский научный журнал, 2024).
