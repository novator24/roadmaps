# Аспирантура механико-математического факультета МГУ

## Список экзаменов
Вступительные экзамены в аспирантуру механико-математического факультета МГУ включают:
1. Специальная дисциплина (в зависимости от профиля, например: 1.1.5 Математическая логика, алгебра, теория чисел и дискретная математика; 2.3.5 Математическое и программное обеспечение вычислительных систем и др.)
2. Философия
3. Иностранный язык (английский, немецкий или французский)

Экзамены проводятся в устной форме. Дополнительно оценивается реферат по теме предполагаемой диссертации.
